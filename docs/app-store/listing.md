# 포실이 App Store 등록 문구

App Store Connect → 앱 → (버전) 화면에 그대로 붙여 넣으면 됩니다. 괄호 안은 글자 수 제한입니다.

## 기본 정보

| 항목 | 내용 |
|---|---|
| 이름 (30자) | 포실이 - 할일·일기·기록 다이어리 |
| 부제 (30자) | 감자 친구와 함께 쓰는 하루 기록장 |
| 기본 카테고리 | 생산성 |
| 보조 카테고리 | 라이프스타일 |
| 연령 등급 | 4+ (설문에서 모두 "없음") |
| 가격 | 무료 |

> 이름 "포실이"만 쓰고 싶으면 이름에 `포실이`, 부제에 `할일·일기·습관을 한 곳에 기록`을 넣어도 됩니다. 이름에 핵심 단어를 넣으면 검색에 더 잘 걸립니다.

## 프로모션 텍스트 (170자, 심사 없이 언제든 수정 가능)

잠금화면 버튼 한 번으로 할일을 바로 적고, 손글씨로도 기록하세요. 오늘 할일·일기·일정·습관을 감자 친구 포실이가 함께 챙겨 줍니다.

## 스크린샷 구성 (6.9인치, 1320 × 2868)

순서가 곧 첫인상입니다. 앞의 3장이 검색 결과에 바로 보이니 가장 중요한 기능을 앞에 둡니다.
각 장의 화면을 시뮬레이터(iPhone 16 Pro Max)에서 `Cmd + S`로 찍은 뒤, `screenshot-maker.html`로 문구를 얹어 내보내세요.

| # | 찍을 화면 | 큰 문구 | 작은 문구 |
|---|---|---|---|
| 1 | 오늘 할일 탭 (할일 4~6개, 일부 완료) | 오늘 할 일만 쏙 | 백로그에서 골라 오늘에 집중해요 |
| 2 | 백로그 추가 화면 – 손글씨 입력 중 | 손글씨로 슥슥 | 쓰면 글자로 바로 인식돼요 |
| 3 | 잠금화면 하단 버튼 / 제어 센터 | 잠금화면에서 바로 추가 | 떠오른 할일, 앱 찾지 말고 한 번에 |
| 4 | 일기 달력 (대표 사진이 여러 칸) | 사진으로 채우는 일기 달력 | 하루 한 장, 나만의 기록 |
| 5 | 홈 화면 – 일정·디데이·날씨 위젯 | 위젯으로 한눈에 | 오늘 일정과 디데이를 홈 화면에 |
| 6 | 습관 트래커 | 매일 쌓이는 습관 | 체크할수록 늘어나는 기록 |
| 7 | 뽀모도로/공부 타이머 | 집중한 시간까지 기록 | 잠금화면에서도 타이머 확인 |
| 8 | 프로젝트 기록 상세 | 입력하면 바로 저장 | 프로젝트별 기록을 깔끔하게 |
| 9 | 포실이 성장(농장) 화면 | 기록할수록 자라는 포실이 | 젤리를 모아 포실이를 키워요 |

**스크린샷 팁**
- 시뮬레이터 상태 표시줄을 깔끔하게: 터미널에서 `xcrun simctl status_bar booted override --time 9:41 --batteryLevel 100 --cellularBars 4`
- 데모 계정에 그럴듯한 샘플 데이터(할일, 일기 사진, 일정)를 미리 넣어 두세요. 실제 개인 정보가 보이지 않게 주의하세요.
- Apple Watch 스크린샷도 필요합니다(워치 앱 포함 시). Apple Watch Ultra 시뮬레이터에서 찍은 원본(410 × 502)을 그대로 올리면 됩니다. 문구 합성은 필요 없습니다.
- 6.9인치만 올리면 작은 iPhone 크기는 자동으로 축소되어 쓰입니다.
- **iPad:** 지금 iOS 앱 타깃이 iPhone + iPad(`TARGETED_DEVICE_FAMILY = 1,2`)로 설정돼 있어 13인치 iPad 스크린샷(2064 × 2752)도 필수입니다. iPad 화면을 따로 다듬을 계획이 없다면 Xcode에서 타깃 → General → Supported Destinations에서 iPad를 빼고 iPhone 전용으로 내는 것을 추천합니다(iPad에서도 iPhone 앱 형태로 설치는 됩니다).
